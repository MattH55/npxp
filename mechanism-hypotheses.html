Mechanism-Based Hypotheses

Non-pharmacological intervention × drug combinations, ranked by real cited mechanism and real curated synthetic-lethality/drug-target data — not a calibrated synergy score.

Why this page exists instead of a prediction model. This project tested whether expression-signature similarity/composition predicts real measured drug interaction — twice: a pathway-feature model trained on 2,924 real ALMANAC/DrugComb pairs, and a much larger, more rigorous test on 739,964 real DrugComb measurements across 288 cell lines, including a shuffle-ablation control. Neither found a real signal (residual correlation ≤ 0.02–0.04 against drugs, against a real positive control reaching 0.2–0.3). So nothing on this page is a learned score. Every row instead traces to two independent real citations: (1) a real paper showing the modifier induces a specific gene/pathway state, and (2) a real curated synthetic-lethality pair or drug-target interaction linking that state to the drug.
Methodology

induced_hr_deficiency: the modality degrades or suppresses a real DNA-repair gene (e.g. mild hyperthermia degrades BRCA2 and inhibits homologous recombination — Krawczyk et al., PNAS 2011), phenocopying a loss-of-function mutation without one. The induced gene is looked up in SynLethDB 3.0 (37,943 real curated human synthetic-lethality pairs) for real SL partners, then in DGIdb 5.0 for real approved anticancer drugs targeting each partner.

pathway_suppression: the modality suppresses a real signalling pathway's activity rather than causing a repair defect (fasting/caloric restriction suppressing IGF-1/PI3K/AKT/mTOR — Nencioni et al., Nat Rev Cancer 2018). The literature's own recommended drug class is used directly, cross-referenced to DGIdb only to find real approved drugs in that class.

immune_mobilization: the mechanism is immune-cell trafficking (exercise mobilising NK cells via epinephrine/IL-6 — Pedersen et al., Cell Metabolism 2016), not a tumour-intrinsic state, so it is paired with real approved immune-checkpoint inhibitors (PD-1/PD-L1/CTLA-4-targeting, filtered to direct inhibitor/antagonist/blocker claims, not DGIdb's broader "immunotherapy" flag, which also catches immunosuppressants like sirolimus).

Evidence tier (induced_hr_deficiency rows only): SynLethDB's own evidence-type hierarchy — CRISPR/CRISPRi (a measured double-knockout result) > High/Low-throughput screen or curated database > computational prediction > text mining (an NLP-extracted literature claim, the weakest evidence SynLethDB carries).

Direct experimental support (gold badge): a handful of rows have a second, independent real paper that tested this exact modifier + this exact drug target together (e.g. heat + PARP inhibitor + cisplatin, Krawczyk et al., Oncotarget 2017) — these are the strongest entries on the page, not because of a higher score, but because they've actually been tested in combination.

ClinicalTrials.gov column: a real, direct ClinicalTrials.gov v2 API cross-check for this exact modifier + drug combination (scoped to the strongest-evidence rows only). "No registered trial found" means the search found nothing — a candidate white-space gap, not proof none exists. The search is a literal substring match on each real trial's own intervention names and title (including brand/device names, e.g. "Optune" for Tumor Treating Fields) after ClinicalTrials.gov's own fuzzy query.intr ranking surfaces candidates — not exhaustive, and a trial using unlisted terminology for the same modality can still be missed.
